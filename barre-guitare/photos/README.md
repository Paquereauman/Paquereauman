# Photos du site Barré guitare

Dépose ici tes images, avec **exactement** ces noms (JPG, JPEG, PNG ou WEBP).
Le site les affiche tout seul à la place des cases « Ta photo ici ». Une case sans fichier reste vide.

Format conseillé : paysage 4:3, 1000 à 1600 px de large, moins de 300 Ko, bien éclairé, fond uni.

| Nom du fichier | Ce que montre la photo |
|---|---|
| `front.jpg` | L'index à plat sur les cordes, vu de face |
| `cross.jpg` | Le barré vu du dessus : l'index roulé sur son côté osseux, le pouce derrière |
| `idx-ok.jpg` | Index au bon endroit, juste derrière la frette ✓ |
| `idx-far.jpg` | Index trop loin de la frette ✗ |
| `idx-on.jpg` | Index sur la frette ✗ |
| `th-ok.jpg` | Pouce vertical, perpendiculaire au manche, derrière l'index ✓ |
| `th-over.jpg` | Pouce couché à l'horizontale le long du manche ✗ |
| `th-low.jpg` | Pouce trop haut ou trop bas ✗ |
| `rear.jpg` | Main complète vue de derrière |
| `pm-ok.jpg` | Espace entre la paume et le manche, poignet droit ✓ |
| `pm-touch.jpg` | Paume collée au manche ✗ |
| `pm-bent.jpg` | Poignet trop plié ✗ |
